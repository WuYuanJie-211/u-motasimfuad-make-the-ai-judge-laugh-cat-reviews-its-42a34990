A one-star review written by a house cat about its human: deadpan, single line, under 200 characters. The cat's heated bed got taken over by a laptop, so the cat reclaims the warmth the only way a cat would — by sleeping on the keyboard.

Run it with:

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and verifies the round-trip.
